# Архітектура інструментів

Інструменти є окремим шаром для взаємодії НейроЛесі із зовнішніми системами.

## Початкові категорії

- GitHub;
- файли та документи;
- зовнішні сервіси;
- системні операції, доступні застосунку.

## Контракт інструмента

Кожен інструмент має описувати:

- призначення;
- доступні операції;
- вхідні параметри;
- формат результату;
- необхідні дозволи;
- можливі помилки.

## Принцип безпеки

Інструмент не повинен отримувати більше доступу, ніж необхідно для конкретної операції. Операції, які можуть змінювати або видаляти дані, мають бути контрольованими.

## Взаємодія

Ядро → Orchestrator → інструмент → результат → Orchestrator → ядро.
