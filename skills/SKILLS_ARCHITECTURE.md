# Архітектура навичок

Навичка — спеціалізована здатність НейроЛесі виконувати певний клас задач.

## Структура навички

- назва та призначення;
- умови використання;
- необхідний контекст;
- доступні інструменти;
- алгоритм або інструкції;
- обмеження;
- критерії успішності;
- версія.

## Життєвий цикл

**Визначення → Реєстрація → Тестування → Використання → Оцінка → Оновлення**

Нові навички не повинні автоматично отримувати необмежені права доступу.
