# Архітектура ядра НейроЛесі

## Призначення

Ядро є центральним координатором НейроЛесі. Воно не виконує всі функції самостійно, а визначає, які компоненти та інструменти потрібно залучити для виконання запиту.

## Компоненти

### Input
Приймає повідомлення користувача та передає його на подальшу обробку.

### Intent
Визначає намір користувача та тип завдання.

### Context
Формує робочий контекст із поточного діалогу, пам'яті, активного режиму та активного проєкту.

### Orchestrator
Координує виконання. Визначає послідовність дій та залучає необхідні модулі й інструменти.

### Response
Збирає результат виконання та формує відповідь користувачу.

## Потік

**Input → Intent → Context → Orchestrator → виконання → Response**

## Принцип

Ядро повинно залишатися модульним. Додавання нової можливості має відбуватися через підключення нового спеціалізованого модуля або інструмента, а не через постійне ускладнення самого ядра.

## Подальший розвиток

На наступних етапах кожен компонент може отримати окрему реалізацію, тести та API-контракт.
