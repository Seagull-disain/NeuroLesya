# Перший прототип ядра

Мета цього каталогу — підготувати мінімальну реалізацію ядра НейроЛесі без прив'язки до конкретного AI-провайдера.

## Мінімальний потік

`Input → Intent → Context → Orchestrator → Response`

## Компоненти прототипу

- `input` — нормалізація вхідного повідомлення;
- `intent` — визначення типу запиту;
- `context` — підготовка контексту;
- `orchestrator` — вибір наступної дії;
- `response` — формування результату.

## Вимога до першої версії

Прототип повинен бути простим, тестованим і розширюваним. Він не повинен містити секретів, API-ключів або жорсткої прив'язки до конкретного постачальника моделі.

Після перевірки базового потоку до нього підключатимуться пам'ять, інструменти та реальні AI-моделі.
