# Архітектура менеджера завдань

## Призначення

Менеджер завдань перетворює складні запити на керовану послідовність дій.

## Життєвий цикл

**Запит → План → Виконання → Перевірка → Результат → Завершення**

## Основні можливості

- створення завдання;
- декомпозиція складного завдання;
- визначення залежностей;
- відстеження стану;
- повторне виконання невдалого кроку;
- перевірка результату;
- збереження важливих рішень у пам'яті.

## Стани

Початковий набір: `new`, `planned`, `in_progress`, `waiting`, `completed`, `failed`, `cancelled`.

## Принцип

Менеджер завдань координує роботу, але не повинен дублювати функції спеціалізованих модулів та інструментів.
